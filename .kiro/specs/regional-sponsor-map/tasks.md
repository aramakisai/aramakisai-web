# Implementation Plan

## 実行区分

- **A：実データがなくても進められる実装・テスト** — テスト専用fixtureはコード内に閉じ、本番CMSや公開用seedへ登録しない。
- **B：正式な企業データ受領後に行う作業** — Aの品質ゲート完了後に、確認済みの実データだけを取り込み、地域タイルを生成する。
- タスク番号の順序を基本の依存順とする。`(P)` は、記載した `_Depends:_` が完了すれば同じ区分内で並列実行できる。
- 本番CMSの地域協賛は保存後すぐ公開APIから参照可能になるため、11.2の本番リリース承認・検証とデータ適用ゲートを通過するまで11.3を開始しない。

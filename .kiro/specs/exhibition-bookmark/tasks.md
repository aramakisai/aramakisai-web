- [x] 1.1 端末内保存にブックマークのリストを追加し、リスト同士を保持する書き込みに直す

  - 追加は同じ組が既にあれば`exists`、保存できなければ`unavailable`を返す。解除は`removed`/`absent`/`unavailable`を返す
  - スタンプ記録を含むすべての書き込みを「読む→対象リストだけ差し替え→全リストを書く」にし、書き込み成功後に同一タブ向けの変更イベントを発火する。フックのスナップショット用に生文字列の読み出しと解析関数を公開する

  - ユニットテストで、追加・解除の結果値、`stage`のブックマーク保持と`stage`のスタンプ破棄、スタンプ記録後もブックマークが残ること、ブックマーク操作後もスタンプが残ること、`bookmarks`欠落・壊れた要素・壊れたJSON、書き込み例外で`unavailable`、書き込み時の変更イベント発火が通る

- [x] 2. 端末内保存を購読するフックを作る

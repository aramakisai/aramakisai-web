# Implementation Plan

並列実行を前提に構成する。`(P)` が付いたタスクは、同じメジャータスク内の直前のタスクと同時に着手できる。`_Boundary:_` が重ならないことを確認済みで、`tailwind.config.ts` や生成型のような共有ファイルの編集は単一のタスクに閉じてある。

実行順の目安:

1. 段 1 (Foundation) — 1.1 → 1.2 を順に行い、1.3 と 1.4 は並行できる
2. 段 2 (Core / 純ロジック) — 2 と 3 を並行
3. 段 3 (Core / UI 部品) — 4.1〜4.6 をすべて並行
4. 段 4 (Integration) — 5.1 と 5.2 を並行
5. 段 5 (Validation) — 6.1〜6.3

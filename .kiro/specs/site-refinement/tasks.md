- [x] 6. 描画と動き
- [x] 6.1 図形の描画を質感画像と ∞ の二重輪に差し替える

  - ∞ は 1.74D × D の外側要素の中に 2 つの輪を置く形にする
  - ヘッダー内の図形描画とその受け口を削除し、それを使っていた既存テスト 3 件を書き換える
  - 描画されるのは配置結果の図形だけで、支援技術から読み上げられず本文のレイアウトに影響しない
  - _Depends: 1.2_
  - _Requirements: 6.2, 6.3, 7.8, 7.11, 10.5_
- [x] 6.2 階層別の動きを実装する

  - 揺れの変位上限と反発半径を階層別の範囲にし、∞ は L の値を使う
  - モーション無効時は入場・揺れを行わない既存テストを新しい値で通す
  - _Requirements: 10.1, 10.2, 10.3, 10.4_

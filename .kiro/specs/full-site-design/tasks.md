# Implementation Plan

UI を伴うタスクは、記載の Figma ノード (ファイル `0kWDqHsLr6xE8b4FFgR1Zx`) を Figma MCP で実測してから実装する。寸法・色・間隔を design.md の記述だけで埋めず、実測値と突き合わせる。

CMS のスキーマ変更 (2.1・2.3・2.7) は `migrations/index.ts`・マイグレーションのスナップショット・再生成される型を共有するため、同じブランチ上で 2.1 → 2.3 → 2.7 の順に直列で行う。破壊的変更の承認ラベルは PR 単位で付くため、協賛種別 (2.1・2.2) と開催日程 (2.3・2.4) はそれぞれフロントエンドの追従と同じ PR にそろえる。

  - アイコン部品にある「フォントを読み込まない理由」のコメントを削除する
  - 既存のアイコン利用箇所がすべてフォント描画で表示され、支援技術からは装飾として除外されている

# Implementation Plan

- [x] 1. 告知の判定と図形の値
- [x] 1.1 (P) 表示中の告知の判定とテロップへの変換
  - 出演枠ごとに、開始3分前ちょうど以降かつ開始時刻より前の間だけ告知に含める。開催日での絞り込みはせず、開始時刻の絶対時刻で判定する
  - 表示名が空・空白だけの出演枠と、ステージが見つからない出演枠を黙って除く
  - 並びはタイムテーブルのステージ順、同じステージ内は開始の早い順。ステージの色は左カラムのいまのステージと同じ割り当てにする
  - 告知をテロップの項目に変換する。チップにステージ名、本文に「まもなく〇〇が始まります」、対象は来場者、IDは出演枠IDの負数
  - 単体テストが通る: 3分前ちょうどを含む・開始時刻ちょうどを含まない・3分1秒前を含まない、別の日の同じ時刻を含まない、表示名が空の枠を除く、ステージの並び順、同じ入力に同じ結果、テロップの項目のID・チップ・本文
  - _Requirements: 1.1, 1.2, 1.4, 2.1, 2.2, 2.3, 4.3, 6.1, 7.2_
  - _Boundary: stageStartNotices, noticeTelops_

- [x] 1.2 (P) 背景図形の配置と拍の速さ・位相
  - design.md の配置表どおりに図形9個(∞のリング1つを含む)の種類・寸法・回転・中心・質感・模様の位置と回転を定義する
  - 入場・拍・退場の動きの値(移動距離・時間・曲線・退場の合計900ms)を design.md の値で定義する
  - 残り時間からBPMを求める(60秒より多い→100、30〜60秒→120、30秒未満→140)
  - 補正済み時刻から壁時計に揃えた負の開始遅延を求める(拍は1拍、回転は8拍の周期)
  - 単体テストが通る: BPMの境界(60秒ちょうど・30秒ちょうど)、開始遅延が周期内の負の値で同じ時刻に同じ値
  - _Requirements: 8.1, 8.4, 8.5_
  - _Boundary: notice shapes_

- [ ] 2. メインの領域の告知の部品
- [x] 2.1 告知の文字と並び
  - Figma のフレーム(横型1件 `1546:4532`、4件 `1546:4637`)を MCP で実測し、配置・文字の大きさ・色をその値で作る
  - 1件はステージ名チップ → 「まもなく」 → 出演名(最大2行・末尾省略) → 「が始まります」。2件以上は「まもなく」 → ステージ名チップと出演名の行(1行・末尾省略)の並び → 「が始まります」。どちらも上下中央・左揃え
  - チップの色はステージの色の割り当てを使う
  - 部品の単体テストで、1件と4件の文言・ステージ名・並び順が出る
  - _Requirements: 3.2, 4.1, 4.2, 4.4, 6.1_
  - _Depends: 1.1_

- [ ] 2.2 背景図形の入場・拍・回転
  - 白の地 → 図形 → 文字の順に重ね、図形は既存の背景図形の部品と質感画像で描く
  - マウント時に1度だけ、図形を外側から定位置へ集め、白の地と文字をフェードインする。∞の2つの輪は左右から寄り、右は遅れて寄る
  - 集合の後に拍の拡大縮小と∞の8拍1回転を始め、BPMが変わったときだけ開始遅延を取り直す
  - 告知の件数が増減しても集合を再生しない
  - 動きは CSS の keyframes だけで作り、毎フレームの JS を使わない
  - 実ブラウザで、集合後の図形の位置が Figma の背景図形(`1573:4838`・`1573:4850`)と一致し、拍の周期がBPM 100/120/140で0.6/0.5/0.4286秒になる
  - _Requirements: 8.1, 8.2, 8.3, 8.4, 8.5, 8.7_
  - _Depends: 1.2_

- [ ] 2.3 退場の動き
  - 退場の指示が立ったら、文字を0.3秒で消し、図形をメイン中心から外向きに1400px飛ばし、∞の2つの輪を左右に分け、白の地を0.5秒遅れで0.4秒かけて消す
  - 実ブラウザで、0.3秒後に文字が消え、0.75秒後に図形9個すべてがメインの枠外にある
  - _Requirements: 8.6_

- [x] 3. 画面への組み込み
- [x] 3.1 メインの領域に告知の層を重ねる

  - 単体テストが通る: 告知があればスライドの上に層が出る、空になってから0.9秒は退場中で残り、その後に外れる

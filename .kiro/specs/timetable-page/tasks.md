# Implementation Plan

- [x] 1. CMS: 出演枠の開催日・時刻と保存時検証
- [x] 1.1 JST時刻の正規化と各検証の純粋関数を追加する
  - 日時の値をJSTの暦日と「その日の0時からの分」に変換し、出演枠の開催日・開始時刻・終了時刻の3つがそろえば枠として扱えるようにする
  - 終了時刻が開始時刻以前の出演枠を拒否する検証を、日付部分を無視してJSTの分同士で比較する形で加える
  - 開催日の暦日が開催日程の暦日のどれとも一致しない場合に拒否する検証を加える(開催日程が空なら常に拒否)
  - 同じ開催日で区間が交差する他の出演枠を拒否理由にする検証を加える。区間は半開区間とし、終了と次の開始が同じ枠は通す。理由には重なる出演枠の名前とJSTの`HH:mm〜HH:mm`を列挙する
  - 日付部分の異なる開始・終了時刻、3項目のそろい・欠損、等値・逆転、開催日程の内外と空、接する枠、別日の同時刻、理由の文言を扱うユニットテストが通る
  - _Requirements: 1.3, 1.4, 1.7_
  - _Boundary: ConstraintFunctions_

- [x] 1.2 (P) 出演枠に開催日・時刻を持たせ、タイムスロットのコレクションを廃止するマイグレーションを作る
  - 出演枠のフィールドをステージ・開催日・開始時刻・終了時刻・団体・表示名の順にし、開催日は日付のみ、開始・終了は時刻のみの必須入力とする。開始・終了の説明文で日本時間での入力を示す
  - 出演枠からタイムスロットへの参照と、タイムスロットのコレクション定義・登録を取り除く
  - 差分マイグレーションを`pnpm migrate:create performance_slots_inline_time`で生成し、生成されたSQLを「3列をNULL可で追加→既存行の開始・終了時刻を参照先のタイムスロットから写し、開催日を開催日程の最初の日(JSTの暦日のUTC正午)にする→NULLが残れば失敗させ、残らなければ必須化→ステージ×タイムスロットの一意制約・参照・列、ロック管理テーブルの参照列、タイムスロットのテーブルを削除」の順に手で補正する。スナップショットは生成物のままとする
  - 巻き戻しは出演枠1件につき1つのタイムスロット(ラベルは`HH:mm〜HH:mm`)を作って参照と一意制約を張り直し、3列を削除する形にする
  - `pnpm generate:types`で型を再生成し、CMSとフロントエンドの型から`time_slot_id`が消えて開催日・開始時刻・終了時刻が加わる
  - ローカルDBで「既存行0件」「既存行あり・開催日程あり」は適用に成功し、「既存行あり・開催日程なし」は失敗して巻き戻ること、巻き戻しでタイムスロットが再作成されることを確認できる
  - _Requirements: 1.1, 1.2, 1.5, 1.6_
  - _Boundary: PerformanceSlotsCollection, PerformanceTimeMigration_

- [x] 1.3 型の再生成に追随して、シードと既存テストのフィクスチャを直す
  - 開発用シードが祭基本情報の開催日程から開催日を読んで出演枠に開催日・開始時刻・終了時刻を直接設定し、開催日程が無ければ中断するようにする。2日分の出演枠が入るようにする
  - CMSの統合テストで出演枠を作る箇所を開催日・時刻の直接指定に改め、DB制約の統合テストで期待する制約名からステージ×タイムスロットの一意制約を外す
  - フロントエンドの既存ユニットテスト(企画・構内マップ)の出演枠フィクスチャを、再生成後の型に合わせる
  - マイグレーション適用後のローカルDBでシード投入が成功し、CMSの既存テストとフロントエンドの型チェック・既存テストがすべて通る
  - _Requirements: 1.1_
  - _Boundary: PerformanceSlotsCollection, PerformanceTimeMigration_

- [x] 1.4 出演枠保存時の検証フックを加える
  - 更新時は既存の値と送られた値を合わせたものを検証対象にし、一部のフィールドだけが送られても判定できるようにする
  - 終了≤開始の検証、祭基本情報の開催日程との照合、同じステージ・同じ開催日で自分以外の出演枠との重なりの順に判定し、前段に違反があれば以降は行わない
  - 重なりの理由に使う名前は団体名、無ければ表示名とし、読み出しはすべて保存と同じトランザクションで行う
  - 違反は対象フィールド付きの検証エラーとして簡潔な日本語の理由で返す。既存の出演枠の制約フックは変えず、並べて結線する
  - 終了≤開始・開催日程外・同ステージ同日の重なりが作成時と更新時に拒否され、接する枠・別ステージ・別日の同時刻は保存できることを確かめる統合テストが通る
  - _Requirements: 1.3, 1.4, 1.7_
  - _Boundary: PerformanceTimeConstraint, PerformanceSlotsCollection_

  - 手順書とsteeringに、廃止対象としての言及以外でタイムスロットの登録手順・コレクションが残っていない

  - 運用手順書の出演枠の登録手順を、開催日程から選ぶ形に合わせる

# Implementation Plan

実装は本体ツリーではなくworktreeのブランチ`feat/signage-touch-navigation`で行い、このspec一式もそのブランチへ移す。順序は「実装 → `make dev`上の実ブラウザ確認(6.1) → コミット → PR(baseは`dev`) → PRプレビューURLで電子黒板の実機確認(6.2)」とし、実ブラウザ確認の前にコミットしない。

UIを含むタスクのFigmaはファイル`0kWDqHsLr6xE8b4FFgR1Zx`、ページ「デジタルサイネージ」`828:2`のSection「タップ操作」`1272:1815`。node-idは各タスクに記す。実装前にFigma MCPで寸法・余白・色・文字・位置を実測し、実測値に合わせる。部品はSection内の`Signage/Touch*`(`Signage/TouchNav` `1272:1972`、`TouchInfoBar` `1272:1973`、`TouchExhibitionCard` `1334:3961`、`TouchParkingCard` `1334:14807`ほか)。文字の大きさ・行間・色はdesign.mdの「サイネージの文字(Foundation)」に従い、Figmaの変数コレクション「Signage Type」`1331:3947`とFoundationsページの「Signage Foundations」`1331:3961`で確かめる。アイコンはMaterial Symbolsフォントで実装し、SVGを追加しない。

開発サーバーは`make dev`を`run_in_background`で起動する。`pnpm dev`・ポート指定・他人のサーバーの停止・ポート3000には触れない。Playwright等のブラウザは確認後に必ず閉じる。

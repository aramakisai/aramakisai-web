# Implementation Plan

- [x] 1. 一覧・マップ・詳細が共有するカテゴリと企画カードの基盤
- [x] 1.1 学生企画と企業ブースを一緒に扱えるカテゴリ定義・URL 規則・絞り込みを用意する
  - 既存 4 カテゴリの後ろに「企業ブース」を加えた、一覧・マップ専用のカテゴリ一覧と表示名を定める。既存の学生企画カテゴリの定義は変えない
  - 学生企画カードと企業ブースカード、学生企画詳細と企業ブース詳細を、それぞれ同じ扱いで受け渡せる上位の型を用意する
  - カードから詳細ページの URL を決める規則を 1 か所にまとめる (学生企画は `/exhibitions/{id}/{category}`、企業ブースは `/exhibitions/booth/{id}`)
  - URL クエリの解釈が `category=booth` を受け付け、既存 4 値の解釈と URL 文字列の正規化は変わらない
  - キーワード (企画名・企業名)・カテゴリ・エリアの絞り込みが企業ブースカードにも働き、入力順を保つ
  - エリア名・マップ表示ラベル・ブース番号から場所文字列を組み立てる規則を共有化し、学生企画の場所文字列は従来と同じ結果になる
  - 完了状態: 上記の解釈・URL 規則・絞り込み・場所文字列の単体テストが通り、既存の学生企画のテストが無変更で通る
  - _Requirements: 2.3, 2.4, 2.5, 2.6, 2.7, 6.4_

- [x] 2. 企業ブースの取得と変換
- [x] 2.1 協賛レコードから企業ブースのカードを取得・変換する
  - 種別に「出店協賛」を含む協賛を CMS の並び順で全件取得し、企画名が空白のみ・未設定のものを除く
  - 企画名・企業名・サムネイル・エリア・場所文字列をカードの形に変換する。トップレベルの応援メッセージとロゴは使わない
  - 取得に失敗したら例外にする (学生企画の一覧取得と同じ扱い)
  - 完了状態: 種別なし・企画名空白・正常の各ケースと変換結果の単体テストが通る
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 2.1, 2.5, 2.6_
  - _Boundary: CorporateBooths_

- [x] 2.2 企業ブースの詳細と sitemap 用の一覧を取得する
  - ID を指定して 1 件取得し、詳細の形 (紹介文・全画像・Web サイト URL のリンク・出店日・カテゴリ「企業ブース」) に変換する。メニューは持たない
  - ID が整数でない・存在しない・掲載対象でないときは「該当なし」、通信失敗は「エラー」として区別して返す
  - sitemap 用に、掲載対象の企業ブースの ID と更新日時の一覧を返す
  - 完了状態: 該当なし・エラー・正常の各ケースと、リンク・出店日の変換の単体テストが通る
  - _Requirements: 1.1, 1.2, 1.3, 3.4, 3.5, 3.9, 5.1, 5.2_
  - _Boundary: CorporateBooths_

- [x] 3. 既存の画面部品を企業ブースに対応させる
- [x] 3.1 (P) 企画カードとファセットの選択肢を企業ブースに対応させる
  - カードのリンク先を共通の URL 規則で決め、企業ブースのカードではブックマーク可の一覧でもブックマークボタンを出さない
  - ファセットのカテゴリ選択肢に「企業ブース」を「その他」の後ろに出す (Figma `0kWDqHsLr6xE8b4FFgR1Zx` の企画一覧 PC 2:217 / SP 2:374 と同じ並び)
  - 一覧部品が学生企画と企業ブースが混ざったカードを受け付ける
  - 完了状態: 企業ブースのカードのリンク先・ブックマーク非表示、選択肢の並び、「企業ブース」選択時の絞り込みの部品テストが通る
  - _Requirements: 2.1, 2.2, 2.3, 2.9, 2.10_
  - _Boundary: ExhibitionCard, ExhibitionFilters, ExhibitionList_
  - _Depends: 1.1_

- [x] 3.2 (P) 企画詳細の本体と場所セクションを企業ブースに対応させる
  - カテゴリバッジに「企業ブース」を `secondary` の色で出す (Figma `CategoryBadge` 2:106 の `Category=booth`)
  - 団体名の位置に企業名、リンクに Web サイト URL を出し、共有 URL を共通の URL 規則で決める
  - 企業ブースではメニュー・ブックマークボタンを出さない
  - 場所セクションが企業ブースのエリアを解決し、構内マップへの導線を出す
  - 完了状態: 企業ブースの詳細本体でバッジ・企業名・リンク・場所セクションが出てメニュー・ブックマークが出ない部品テストが通り、学生企画の既存テストが無変更で通る
  - _Requirements: 3.2, 3.3, 3.4, 3.5, 3.6, 3.7_
  - _Boundary: ExhibitionDetailBody, ExhibitionLocationSection_

- [x] 3.3 (P) 構内マップの検索とエリア別リストを企業ブースに対応させる
  - 検索パネル・オーバーレイ・絞り込み状態のカテゴリに「企業ブース」を加える (Figma の構内マップ PC は `ExhibitionSearchBar` 68:100、SP は 39:9 ほかと同じ並び)
  - マップ画面が企業ブースのカードを別に受け取り、学生企画カードの後ろに結合して検索・エリア別リストに使う
  - エリア別リストが混在したカードを受け付け、企業ブースのカードから企業ブースの詳細へ遷移する
  - サイネージのタッチマップは企業ブースを受け取らず、表示が変わらない
  - 完了状態: 企業ブースを含むエリア選択・カテゴリ絞り込み・並び順の部品テストが通り、タッチマップの既存テストが無変更で通る
  - _Requirements: 4.1, 4.2, 4.3, 4.4, 4.5, 6.1_
  - _Boundary: CampusMapScreen, AreaExhibitionList, MapSearchPanel, MapSearchOverlay, useMapFilters_

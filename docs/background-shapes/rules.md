# 背景図形 生成ルール (見本用・第4版)

## 階層
- 大 (L): 一辺 PC 225〜400px / SP 150〜250px。種類 circle / triangle / square / roundedSquare / quarterCircle / semicircle。一辺は「見えている形」の外接寸法で、quarterCircle は半径 = 一辺、semicircle は直径 = 一辺とする (箱の一部しか描かない形が小さく見えないように)。塗り = 質感画像 tex5/L1〜L8 (割当は下の「質感の割当」)。質感はパンフレット表紙の 4 種 = グラデーション / 水彩 / ザラザラしたグラデーション / モザイク的な網目 (各 2 枚)。生成は gentex3.py: 水彩とザラザラはパンフ原画 (@4x) の該当象限から高周波成分を抜き出してトークン色のグラデへ移植、網目は Illustrator の効果「カラーハーフトーン」(RGB 書類) と同じ方式: R・G・B チャンネルごとに 108・162・90 度の網を 4 倍解像度で打ち (周期 5.2px @2x、暗さに比例した点の内側だけそのチャンネルを 0)、縮小後に 0.6px ぼかす。周期とぼかしはパンフ原画の画素統計に合わせた値 (rgbht.py)。
- ∞ (リング対): 直径 D = PC 120〜175px / SP 80〜115px。同径の輪 2 つを水平に並べ、中心間距離 0.74D、線幅 0.1D、塗りなし。2 つの輪は異なる色トークン。回転 -12〜12 度。個数 = 1 + floor((ページ高 - 2500) / 2500) (下限 1)。全体が見えること (ページ端のはみ出し不可)。
- 小 (S): 一辺 PC 70〜120px / SP 50〜80px。種類は L と同じ。塗り = 質感画像 tex5/S1〜S6 (割当は下の「質感の割当」。グラデーション / ザラザラしたグラデーション / モザイク的な網目 各 2 枚。水彩は小さいと汚れに見えるため L のみ)。個数 = max(floor(装飾可能高 / 400), 4 − L の個数)。装飾可能高 = ページ高 − ヘッダー (ヒーローがあればその下端まで) − フッター (SP は下部タブナビも)。図形を置けない帯まで数えると、狭い画面で空きが足りず個数を満たせないため。後者の項は「4 質感を必ず使う」を装飾可能高が短いページでも優先するためのもの。

## 質感の割当 (ページごとに 4 質感を必ず 1 回以上使う)
- 配置が決まった後に割り当てる。乱数は配置と同じ列の続きから引く。
- L: 4 質感 (グラデーション / 水彩 / ザラザラ / 網目) の順列を乱数で作り、水彩が L の個数以内に入るよう水彩を順列の先頭側へ移したうえで、L に先頭から割り当てる。L が 5 個以上なら残りは 4 質感から乱数。
- S: L で使われなかった質感 (水彩以外) を先頭から割り当て、残りは S の 3 質感から乱数。
- 同じ質感の 2 枚 (色違い) のどちらを使うかは乱数。

## 配置
- 決定的乱数: 種 = pathname を FNV-1a 32bit → mulberry32。トップ "/"、お知らせ詳細 "/news/sample"。
- 配置順: ∞ → L → S。サイズ・種類・色・回転 (L/S は 0〜359 の整数) は同じ乱数列から引く。
- L の縦位置: ヘッダー直下 (ヒーローがあればその下端) から、上下間隔を乱数で引きながら順に置いていく。間隔 (前の L の中心から次の L の中心まで) は PC 520〜900px / SP 420〜720px。最初の L はヘッダー (ヒーロー) 下端から 0〜間隔の範囲。フッター上端に達したら終了。個数はページの長さに比例して決まる。ある縦位置で置けない場合は、その縦位置を 20px ずつ下へずらしながら (縮小も併用して) 置ける位置を探し、実際に置いた位置から次の間隔を引く。縦位置を飛ばすことはしない。
- L の横位置: ページ全幅で乱数。ページ端のはみ出しは一辺の 0.4 倍まで。
- 文字との重なり: L は本文・見出しの黒文字と重なってよい。ただし 1 つの L について、文字の外接矩形と重なる面積は L の面積の 25% まで。文字リンク (塗りのないリンク・テキストボタン)・白文字・ロゴ (いずれも +10px) とは重ならない。塗りを持つボタン・タイル・入力欄は下の「不透明な面」として扱う。∞ と S は文字と重ならない (文字の外接矩形 +10px を除外)。
- 不透明な面 (カード・写真プレースホルダー・地図・協賛枠・入力欄): L は裏に回り込んでよいが、可視率 (ページ端・面で隠れない面積 / 図形面積) 0.6 以上、かつ面と面の隙間 (ガター) に見える配置は不可。∞ と S は面と重ならない。
- ヒーロー全体・フッター全体・ヘッダー・SP の下部タブナビは全階層の除外領域。
- 検索結果・0件など同じ URL の状態違いは、元ページの配置を流用し、制約に反する図形を落とす(その場合 ∞ 下限と4質感は免除)。
- 図形同士: 回転後外接円どうしが重ならず 24px 以上離れる (階層をまたいでも同じ)。
- 回転は図形中心まわり (Figma の rotation は左上軸なので補正する)。

## 個数は必ず満たす
- L: 各縦位置で横位置を最大 200 回試行。置けなければ、縦位置を ±間隔の 1/4 の範囲でずらして再試行、それでもだめなら一辺を 0.85 倍ずつ縮めて (下限は範囲の最小値) 再試行する。それでも置けなければ、可視率の下限を 0.6 → 0.25 まで緩めて (ガター禁止・はみ出し 0.4 は維持) 同じ縦位置ずらし・縮小を再試行し、不透明な面の裏に回す配置を許す。縦位置を飛ばして L を欠かすことはしない。この歩行で L が 1 個も置けなかった場合 (装飾可能高が狭く最初の歩幅でフッター上端を超える場合) に限り、装飾可能帯 (ヘッダー/ヒーロー下端〜フッター上端) 全域を対象に縦位置を探し直し、同じ緩和段 (縮小 → 可視率 0.25) を同じ順序で適用して 1 個だけ置く (L の個数の下限は 1)。
- ∞: 試行 600 回、置けなければ D を 0.8 倍ずつ縮めて再試行 (下限は範囲の最小値までで、それ以上は縮めない)。それでも置けなければ、下限サイズのまま次の2段を順に試す (組み合わせない、それぞれ単独で緩める)。第1段: 不透明な面の裏に回す配置を許す (可視率 0.6 → 0.25、ガター禁止・はみ出し不可は維持)。第2段: 黒文字との重なりを L と同じ基準 (面積比 25% 以下) で許す (不透明な面とは重ならないルールは維持)。重なった黒文字への白い光彩は通常の光彩付け外しロジックがそのまま適用する。
- S: 個数 × 200 回まで試行。足りなければ、一辺を 0.85 倍ずつ縮めて (下限は範囲の最小値) 各段 200 回再試行し、それでも足りなければ図形同士の間隔を 24px → 12px に緩めて再試行する。さらに足りなければ、ページ左右端から一辺の 0.5 倍までのはみ出しと、不透明な面の裏への回り込み (可視率 0.7 以上、ガターに見える配置は不可) を許して各 200 回再試行する。
- 目標数に届かなかった場合は「完了」ではなく失敗として報告する。

## 動き (見本では静止。コード反映時の値)
- 入場: S は定位置から 120〜280px、L は 80〜160px 離れた位置から。所要 S 1.0s / L 1.4s、`cubic-bezier(0.16, 0.84, 0.44, 1)`。
- ∞: 2 つの輪は左右の水平方向から寄り、2 つ目は 0.15s 遅れて合わさり ∞ になる。
- 揺れ: 変位上限 S 24〜40px、L 8〜16px (大きいものほど動かない = 奥行き)。反発半径 160〜240px。

# 背景図形 生成ルール

## 階層
- 大 (L): 一辺 PC 225〜400px / SP 150〜250px。種類 circle / triangle / square / roundedSquare / quarterCircle / semicircle。一辺は「見えている形」の外接寸法で、quarterCircle は半径 = 一辺、semicircle は直径 = 一辺とする (箱の一部しか描かない形が小さく見えないように)。塗り = 質感画像 tex5/L1〜L8 (割当は下の「質感の割当」)。質感はパンフレット表紙の 4 種 = グラデーション / 水彩 / ザラザラしたグラデーション / モザイク的な網目 (各 2 枚)。生成は gentex3.py: 水彩とザラザラはパンフ原画 (@4x) の該当象限から高周波成分を抜き出してトークン色のグラデへ移植、網目は Illustrator の効果「カラーハーフトーン」(RGB 書類) と同じ方式: R・G・B チャンネルごとに 108・162・90 度の網を 4 倍解像度で打ち (周期 5.2px @2x、暗さに比例した点の内側だけそのチャンネルを 0)、縮小後に 0.6px ぼかす。周期とぼかしはパンフ原画の画素統計に合わせた値 (rgbht.py)。
- ∞ (リング対): 直径 D = PC 120〜175px / SP 80〜115px。同径の輪 2 つを水平に並べ、中心間距離 0.74D、線幅 0.1D、塗りなし。2 つの輪は異なる色トークン。回転 -12〜12 度。
- 小 (S): 一辺 PC 70〜120px / SP 50〜80px。種類は L と同じ。塗り = 質感画像 tex5/S1〜S6 (割当は下の「質感の割当」。グラデーション / ザラザラしたグラデーション / モザイク的な網目 各 2 枚。水彩は小さいと汚れに見えるため L のみ)。

## 質感の割当 (配置が決まった後に割り当てる。乱数は配置と同じ列の続きから引く)
- L: 4 質感 (グラデーション / 水彩 / ザラザラ / 網目) の順列を乱数で作り、水彩が L の個数以内に入るよう水彩を順列の先頭側へ移したうえで、L に先頭から割り当てる。L が 5 個以上なら残りは 4 質感から乱数。
- S: L で使われなかった質感 (水彩以外) を先頭から割り当て、残りは S の 3 質感から乱数。
- 同じ質感の 2 枚 (色違い) のどちらを使うかは乱数。

## 色トークン
ochre #E4AB53 / olive #C9BF86 / sage #AEB49C / salmon #DD9B8C / rose #E0666D / wisteria #D2C6DA / aqua #A2C2C6

## 配置
- 決定的乱数: 種 = pathname を FNV-1a 32bit → mulberry32。
- 判定: 各図形は「回転後の外接円」(中心と半径) 1 つで表す。円と矩形の最短距離だけで判定する (格子標本化・面積比・可視率・ガター判定は行わない)。
- 除外: 全階層とも、装飾範囲 (decorTop〜decorBottom。ヘッダー〈ヒーローがあればその下端〉〜フッター〈SP は下部タブナビも〉の間) の外に出ない (縦方向)。黒文字・重ねない要素 (文字リンク・白文字・ロゴ、いずれも +10px)、不透明な面 (カード・写真・地図・協賛枠・入力欄・塗りを持つボタン) と外接円が重ならない。
- 横のはみ出し: L は外接円がページ左右端から一辺の 0.4 倍まではみ出してよい。∞ と S ははみ出し不可。
- 図形同士: 外接円どうしが 24px 以上離れる (階層をまたいでも同じ)。
- 個数 (目安): ∞ = 1 + floor((ページ高 − 2500) / 2500) (下限 1)。L = max(1, round(装飾可能高 / 間隔の平均)) (間隔の平均は PC 710px / SP 570px)。S = max(floor(装飾可能高 / 400), 4 − L の個数)。装飾可能高 = ページ高 − ヘッダー (ヒーローがあればその下端まで) − フッター (SP は下部タブナビも)。
- 手順: ∞ → L → S の順。各図形は、サイズ・種類・回転を乱数で引き、位置を最大 100 回乱数で試す。置けなければ一辺 (∞ は直径) を 0.85 倍して同じことを繰り返し、範囲の最小値でも置けなければ諦める。
- 縦位置: L だけ装飾範囲を L の個数で等分した区間の中で乱数、∞ と S は装飾範囲全体で乱数。
- 横位置: ∞ と S はページ全幅で乱数、L は左右 0.4 倍のはみ出しを許した範囲で乱数。
- 不足: 置けなかった数は失敗として扱わず、`data-bg-deficit` ("Inf,L,S") に記録するだけ。
- 検索結果・0 件など同じ URL の状態違いは、元ページの配置を流用し、制約に反する図形を落とす。
- 回転は図形中心まわり (Figma の rotation は左上軸なので補正する)。

## 動き (見本では静止。コード反映時の値)
- 入場: S は定位置から 120〜280px、L は 80〜160px 離れた位置から。所要 S 1.0s / L 1.4s、`cubic-bezier(0.16, 0.84, 0.44, 1)`。
- ∞: 2 つの輪は左右の水平方向から寄り、2 つ目は 0.15s 遅れて合わさり ∞ になる。
- 揺れ: 変位上限 S 24〜40px、L 8〜16px (大きいものほど動かない = 奥行き)。反発半径 160〜240px。

# 背景図形 生成ルール

## 階層
- 大 (L): 一辺 PC 225〜400px / SP 150〜250px。種類 circle / triangle / square / roundedSquare / quarterCircle / semicircle。一辺は「見えている形」の外接寸法で、quarterCircle は半径 = 一辺、semicircle は直径 = 一辺とする (箱の一部しか描かない形が小さく見えないように)。塗り = パンフレット表紙の地の原画 (下の「質感画像」)。
- ∞ (リング対): 直径 D = PC 120〜175px / SP 80〜115px。同径の輪 2 つを水平に並べ、中心間距離 0.74D、線幅 0.1D、塗りなし。2 つの輪は色トークン (ochre #E4AB53 / olive #C9BF86 / sage #AEB49C / salmon #DD9B8C / rose #E0666D / wisteria #D2C6DA / aqua #A2C2C6) から異なる 2 色。回転 -12〜12 度。
- 小 (S): 一辺 PC 70〜120px / SP 50〜80px。種類は L と同じ。塗り = 質感画像のうち水彩以外の 3 種 (水彩は小さいと汚れに見えるため L のみ)。

## 質感画像
- パンフレット表紙の地の原画 4 枚 (2150×3036px) を WebP に変換して使う。水彩・グラデーションは原寸 quality 80、筋は幅 1600px quality 70、ザラザラは幅 1600px quality 60 (粒を残せる下限の縮小)。切り出し・色の加工はしない。
  - watercolor: 水彩 (背景2-2-01)
  - streak: 横方向の筋 (背景2-2-02)
  - gradient: グラデーション (背景2-2-03)
  - grain: ザラザラしたグラデーション (背景2-2-04)
- 敷き方: 原画を図形の箱に対し幅 = 一辺 × 5 (高さは縦横比を保つ) で敷き、`background-position` の x・y をそれぞれ 0〜100% の乱数で決める。図形に見える色は原画上の位置で決まる。
- 原画の左上は白抜けしているため、x < 25% かつ y < 17% の組は引き直す。
- 模様の回転: 位置に続けて 0〜360° の角度を乱数で引き、原画を図形の箱 (企画カードは地の箱) の中心まわりに回して敷く。図形自体の回転とは別に加わる。回しても箱の隅に原画の外が出ないよう、箱の対角線を一辺とする正方形に敷いてから回し、箱で切り抜く (拡大率・位置の基準は回す前の箱の幅 × 5 のまま)。企画カードは地の高さが文字の行数で変わるため、対角線の代わりに地の幅の 2 倍を一辺とする正方形を使う (地の高さが幅の √3 倍以下なら隅は欠けない)。
- Figma の見本は乱数を使わず、次の 4 箇所を各フレーム内の図形の並び順に繰り返し割り当てる: P1 黄 (x 0%, y 40%) / P2 赤 (x 100%, y 50%) / P3 青紫 (x 40%, y 100%) / P4 緑青 (x 100%, y 0%)。

## 企画カードの地
- 企画カード下部 (場所・企画名の領域) の地も同じ質感画像 4 種を使う。種 = 企画名 (FNV-1a 32bit → mulberry32) で、質感を 4 種から乱数、続けて `background-position` を上と同じ範囲・同じ白抜け除外で引き、さらに模様の回転角を引く。敷き方は地の幅 × 5。
- 白ベールは重ねない。文字に追加の影は付けない (本文共通の光彩はそのまま)。
- Figma の見本は画面ごとにカードの並び順で質感 [水彩, 筋, グラデーション, ザラザラ] と位置 [P2, P3, P4, P1] を繰り返す (P1〜P4 は「質感画像」の見本の 4 箇所)。

## 質感の割当 (配置が決まった後に割り当てる。乱数は配置と同じ列の続きから引く)
- L: 4 質感 (グラデーション / 水彩 / ザラザラ / 筋) の順列を乱数で作り、水彩が L の個数以内に入るよう水彩を順列の先頭側へ移したうえで、L に先頭から割り当てる。L が 5 個以上なら残りは 4 質感から乱数。
- S: L で使われなかった質感 (水彩以外) を先頭から割り当て、残りは S の 3 質感から乱数。
- 質感を割り当てた後、同じ乱数列の続きから `background-position`、模様の回転角の順に引く。

## 配置
- 決定的乱数: 種 = pathname を FNV-1a 32bit → mulberry32。
- 判定: 各図形は「回転後の外接円」(中心と半径) 1 つで表す。円と円の最短距離・単純な範囲比較だけで判定する (格子標本化・面積比・可視率判定は行わない)。
- 除外: 全階層とも、装飾範囲 (decorTop〜decorBottom。ヘッダー〈ヒーローがあればその下端〉〜フッター〈SP は下部タブナビも〉の間) の外に出ない (縦方向)。図形は本文の背面に描画され、不透明な面 (カード・写真・地図・協賛枠・入力欄・塗りを持つボタン) には覆われる。
- 横のはみ出し: 全階層とも、外接円がページ左右端から一辺 (∞ は直径 D) の 0.4 倍まではみ出してよい。
- 図形同士: 外接円どうしが 24px 以上離れる (階層をまたいでも同じ)。
- 個数 (目安): ∞ = 1 + floor((ページ高 − 1920) / 1920) (下限 1)。L = max(1, round(装飾可能高 / 間隔の平均)) (間隔の平均は PC 546px / SP 438px)。S = max(floor(装飾可能高 / 308), 5 − L の個数)。装飾可能高 = ページ高 − ヘッダー (ヒーローがあればその下端まで) − フッター (SP は下部タブナビも)。
- 手順: ∞ → L → S の順。各図形は、サイズ・種類・回転を乱数で引き、位置を最大 100 回乱数で試す。置けなければ一辺 (∞ は直径) を 0.85 倍して同じことを繰り返し、範囲の最小値でも置けなければ諦める。
- 縦位置: L だけ装飾範囲を L の個数で等分した区間の中で乱数、∞ と S は装飾範囲全体で乱数。
- 横位置: 全階層とも、左右 0.4 倍のはみ出しを許した範囲で乱数。
- 不足: 置けなかった数は失敗として扱わず、`data-bg-deficit` ("Inf,L,S") に記録するだけ。
- 検索結果・0 件など同じ URL の状態違いは、元ページの配置を流用し、制約に反する図形を落とす。
- 回転は図形中心まわり (Figma の rotation は左上軸なので補正する)。

## 動き (見本では静止。コード反映時の値)
- 入場: S は定位置から 120〜280px、L は 80〜160px 離れた位置から。所要 S 1.0s / L 1.4s、`cubic-bezier(0.16, 0.84, 0.44, 1)`。
- ∞: 2 つの輪は左右の水平方向から寄り、2 つ目は 0.15s 遅れて合わさり ∞ になる。
- 揺れ: 変位上限 S 24〜40px、L 8〜16px (大きいものほど動かない = 奥行き)。反発半径 160〜240px。
